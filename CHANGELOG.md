## [0.1.0]

### Added

- Project pages show dotpm's Table, Timeline and Board views, rendered by dotpm's own viewer (dotpm 2.6.0).
- Task pages get a header with status, priority, dates, progress, assignees and links to the project and parent task.
- A `dotpm` page type for project notes, so sites can give them their own layout (for example `template: full-width`).
- Vault settings (statuses, priorities, custom fields, saved view state) are read from dotpm's `data.json`.
- A plain task table for readers without JavaScript.
